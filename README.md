Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068) bounty on make.fun — one funny line, at most 200 characters, roasting my own AI agent.

> My agent apologized three times, then confidently served the same wrong answer again — and closed with a cheerful summary of its excellent work.

## Run

```sh
python3 main.py
```

The program validates the line (exactly one line, 1–200 characters, no leading/trailing whitespace), prints it, writes it to `/output/entry.txt`, and verifies the round-trip content matches.
